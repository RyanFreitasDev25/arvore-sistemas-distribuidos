# Árvore Genealógica dos Sistemas Operacionais Distribuídos

Site estático (HTML, CSS e JavaScript puro). Abra `index.html` no navegador para testar localmente.

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie `index.html`, `style.css`, `script.js` e `README.md` para a raiz (branch `main`).
3. Em **Settings → Pages**, em *Build and deployment*, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`, e salve.
4. Após 1–2 minutos o site estará em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

Para editar sistemas ou referências, altere o array `S` em `script.js`.
